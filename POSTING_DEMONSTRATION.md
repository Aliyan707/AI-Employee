## 🔍 Behind the Scenes: How It Works

### **1. Browser Automation (browser-mcp)**
The approval agent uses browser-mcp to:
- Open browser instances for each platform
- Navigate to posting interfaces
- Fill in content programmatically
- Click buttons and submit posts
- Capture URLs for audit trails

### **2. Platform-Specific Logic**
Each platform has different posting mechanics:

**LinkedIn:**
- Click "Start a post" button
- Paste content in rich text editor
- Add hashtags (separate field or inline)
- Click "Post" button
- Wait for confirmation + capture URL

**Facebook:**
- Click "What's on your mind?" or "Create post"
- Paste content (emojis preserved)
- Click "Post" button
- Wait for post to appear in feed
- Capture URL from DOM

**Twitter/X (Thread):**
- Create first tweet
- Wait for publish
- Capture tweet URL
- Reply to first tweet (creates thread)
- Repeat for each subsequent tweet
- Capture thread URL (first tweet URL)

### **3. Error Handling**
If posting fails on any platform:
- Retry once (network issues)
- If still fails, log error
- Create manual posting instructions in `Manual_Post_Instructions/`
- Continue with other platforms
- Alert human via Dashboard.md error log

### **4. Audit Trail**
Every action logged in JSON Lines format:
- Timestamp (PKT timezone)
- Agent (gold-approval)
- Event type (browser_action, post_published, etc.)
- Platform
- Status (success/error)
- URLs captured
- Metadata (word count, character count, etc.)
